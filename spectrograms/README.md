# Spectrogram Files

Place public spectrogram images in this directory.

The current page expects the DNS2020 noreverb files here:

```text
spectrograms/DNS2020/noreverb/noisy/sample_01.png
spectrograms/DNS2020/noreverb/clean/sample_01.png
spectrograms/DNS2020/noreverb/our/sample_01.png
```

Use the same filename stem as the matching audio files.
