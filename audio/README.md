# Audio Files

Place public processed demo audio files in this directory.

The current page expects the DNS2020 noreverb files here:

```text
audio/DNS2020/noreverb/noisy/fileid_101.wav
audio/DNS2020/noreverb/clean/fileid_101.wav
audio/DNS2020/noreverb/our/fileid_101.wav
```

Use the same filename stem across `noisy`, `clean`, and `our`, for example `fileid_102.wav` in all three folders.
