# Audio Files

Place public processed demo audio files in this directory.

The current demo page expects these names by default:

- `noisy_01.wav`
- `dualse_01.wav`
- `noisy_02.wav`
- `dualse_02.wav`
- `noisy_03.wav`
- `dualse_03.wav`

You can edit `index.html` if the final filenames are different.
